# Online Quiz Generator

A beginner PHP + MySQL project inspired by the provided presentation screenshot. This is a reconstructed starter project, not the exact original source code.

## Features
- Teacher and student demo login
- Teacher can create quizzes with one multiple-choice question
- Student can attempt quizzes and submit answers
- Results are stored in MySQL and shown to the teacher

## Requirements
- PHP 8+
- MySQL / MariaDB
- XAMPP (recommended for local Windows setup)

## Run locally
1. Copy the project folder into `C:\xampp\htdocs\quiz-generation-system`.
2. Start Apache and MySQL in XAMPP Control Panel.
3. Open `http://localhost/phpmyadmin`.
4. Import `database.sql`.
5. Open `http://localhost/quiz-generation-system/setup_demo.php` once.
6. Delete `setup_demo.php` from the project folder after setup.
7. Open `http://localhost/quiz-generation-system/`.

Demo teacher: `teacher@demo.com` / `teacher123`  
Demo student: `student@demo.com` / `student123`
